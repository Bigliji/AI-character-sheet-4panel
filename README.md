# character-sheet-4panel

> Agent Skill · 人物三视图 / 四宫格角色设定图生成（Character Sheet / Turnaround）

把一张人物参考照片，转成一张 **2×2 标准化角色设定图**：正面头像、侧面头像、全身正面（面部留白）、全身背面。风格对齐影视选角资料片——中性影棚、平光、无修饰。

---

## 为什么需要这个技能

生成角色设定图时，最常见的失败不是画得不好，而是**人设漂移**：四个面板不像同一个人；面部被美颜滤镜改成了偶像脸；服装细节被"优化"掉；第三面板本该留给后期合成的脸被画上了五官。

这个技能把这些全部写成硬约束，并在生成后用视觉回读逐项验收，而不是凭提示词描述下判断。

## 产出面板定义

| 面板 | 位置 | 内容 |
|---|---|---|
| FACE FRONT | 顶左 | 头肩特写，正对镜头，中性表情 |
| FACE SIDE | 顶右 | 同比例 90° 侧面 |
| BODY FRONT | 底左 | 全身正面站姿，**面部刻意留白**（无眼鼻嘴，供后期编辑） |
| BACK | 底右 | 全身背面，含帽后、背缝、鞋跟高度 |

四面板合并为单图，细白缝分隔，每格角标英文标签。

## 核心约束

1. **参考图是唯一设计源**——禁止从零重绘，禁止风格迁移。
2. **禁止美化**——保留真实肤色、毛孔、脸型，不做瘦脸大眼磨皮。
3. **第三面板面部留白**——这是设定图的生产规范，不是缺陷。
4. **参考图下半身/鞋袜不可见时，必须先向用户确认补全方案**，不得自行默认。
5. **验收不合格不自动重做**，把问题列给用户决定。

## 安装

克隆到 Agent 的技能目录即可生效（目录名需与 `name` 字段一致）。

```bash
git clone https://github.com/Bigliji/character-sheet-4panel.git \
  ~/.workbuddy/skills/character-sheet-4panel
```

```powershell
git clone https://github.com/Bigliji/character-sheet-4panel.git `
  "$env:USERPROFILE\.workbuddy\skills\character-sheet-4panel"
```

## 使用

触发方式为自然语言，例如：

- 「把这张照片做成三视图」
- 「生成角色设定图 / character sheet」
- 「要正面、侧面、全身、背面四个面」
- 「四宫格人物设定，影视选角那种」

**前置条件**：执行端必须具备**图像编辑能力**（带参考图的派生生成）。纯文生图会丢失人物身份，本技能不适用。

## 已知限制

- 成图自带平台「AI 生成」水印，属合规标识，无法通过重新生成去除。
- 参考图上的文字（如帽子绣字）只能风格化近似，无法逐字还原。
- 清晰度受模型支持尺寸上限约束，4K 请求可能降级到同尺寸比例的较小档（如 9:16 实出 1072×1920），降级时会在交付说明中如实标注。
